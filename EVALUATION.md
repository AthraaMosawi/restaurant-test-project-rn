# Evaluation Criteria 
(Included for self-evaluation if needed)

### Technical Skills (40%)
- Proper React Native patterns and component structure
- State management implementation
- Cart logic (add, remove, quantity updates, totals)
- Navigation flow and data passing
- Code organization and reusability

### Problem Solving (25%)
- How they structure the menu data
- Cart state management approach
- Handling edge cases (empty cart, out of stock items)
- Performance considerations for menu lists

### UI/UX Implementation (25%)
- Visual appeal and food app aesthetics
- User experience flow from menu to cart
- Proper use of React Native components
- Responsive design and layout
- Cart interaction feedback

### Code Quality (10%)
- Clean, readable code structure
- Consistent naming and organization
- Proper component separation
- TypeScript usage (if applicable)

## Bonus Points
- Category filtering with smooth transitions
- Search functionality
- Item customization options
- Order summary calculations (tax, delivery fee)
- Animated cart interactions
- Pull-to-refresh on menu
- Offline menu caching
- Dark mode support

## Deliverables
1. Complete React Native project code
2. README with setup and run instructions
3. Brief explanation of state management approach
4. Screenshots of key screens
5. Any design decisions and trade-offs made

## Discussion Points
- Walk through the cart state management
- Explain menu data structure decisions
- Discuss UI/UX choices for food presentation
- How would you handle real restaurant features (orders, payments, user accounts)?
- Performance optimization strategies for large menus
- How would you implement real-time menu updates?
